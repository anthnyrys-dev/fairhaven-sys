# 7. One client appears under two names

**What we found**
"Harrow Property Care" is used on four jobs, and "Harrow Property Care Pty Ltd" is used once — same phone number, same email address, clearly the same client.

**What we did**
Clients are matched by email address, not by name, so both spellings collapse into one client record. Whichever name appeared first ("Harrow Property Care") became the name shown in the system.

**Ask the client?**
Worth a quick check, not a blocker — should invoices and the client record read "Harrow Property Care" or the full "Pty Ltd" form?
